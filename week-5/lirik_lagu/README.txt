MY MUSIC SPACE - REVISI PRAKTIKUM

1. Copy folder lib ke project Flutter kamu.
2. Gunakan pubspec.yaml ini sebagai acuan dependencies/assets.
3. PENTING: copy kembali file asli milikmu:
   assets/Nadin.jpg
   assets/bertaut.mp3
   File tersebut tidak disertakan dalam ZIP ini karena tidak diunggah pada percakapan ini.
4. Isi lirik.dart pada paket ini hanya placeholder. Jika lirik.dart lama kamu sudah benar, pertahankan file lama tersebut.
5. Tambahkan permission Android sesuai ANDROID_PERMISSION.txt.
6. Jalankan:
   flutter clean
   flutter pub get
   flutter run

Fitur:
- Music player
- Play/Pause, Stop, maju/mundur 10 detik
- Favorite
- Slider
- Lirik buka/tutup
- Drawer, BottomNavigationBar, TabBar
- ListView, GridView, PageView, ReorderableListView, Wrap
- Form/Input
- Dialog, SnackBar, BottomSheet, Tooltip
- Animation
- FutureBuilder, StreamBuilder, InheritedWidget, ValueListenableBuilder
- Cupertino widgets
- Kamera/Galeri
- GPS
